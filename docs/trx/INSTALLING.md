## Installing on iOS

Once you installed TRX on your iDevice, open it, you will see the error `No Playable Mods Avaible`, this is normal because at the 1st installation of the app, it must create the Documents folder on the Files app.

So now open the Files app, go to `Downloads`, extract the `TRX Assets.zip` file, select all the extarcted files and click on `Copy`.
Return backl to `On my iPhone`, open the `TRX` folder, and there paste the folders you copied before, by also clicking `Merge` when prompted

Now you must own a copy of the original games TR1-2-3 and drop the game files on your iDevice. Once you dropped them, you can just copy the game files as a normal TRX installation

All done! Open TRX and enjoy!
